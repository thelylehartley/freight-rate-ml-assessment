Freight Rate Prediction — Machine Learning Assessment
This project predicts posted freight rates using a CatBoost regression model. It includes data exploration, cleaning, feature engineering, chronological model validation, final predictions for 12,000 loads, and the required fixed December prediction chart.

Setup
From the project root, install the dependencies:
python -m pip install -r requirements.txt
Open the project in VS Code with the Python and Jupyter extensions installed. Select a Python environment with the dependencies installed. If the environment cannot start a notebook kernel, install ipykernel in that environment.

Ensure the models/, outputs/, and outputs/scorer_results/ directories exist before running the notebook. The models/ directory is ignored by Git.
Reproduce training and predictions
1. Open notebooks/01_explore.ipynb in VS Code.
2. Make sure the notebook's working directory is notebooks/. Its relative paths (such as ../data/train-test.csv) assume that location.
3. Restart the kernel and Run All cells from top to bottom. The notebook performs exploration, the chronological split, model comparisons, final training, and both prediction exports.
4. Confirm the following files were generated:
   - outputs/model_comparison.csv
   - models/freight_catboost.cbm
   - outputs/validation_predictions.csv
   - outputs/december_predictions.csv
The final prediction CSV contains exactly load_id,predicted_rate, with one row for each of the 12,000 validation loads. The December CSV preserves the seven columns from its provided input file and fills predicted_rate for all 31 dates.
Approach
- Split: January–August 2025 for training; September–October 2025 as a chronological holdout (38,477 training and 9,523 holdout loads). This tests performance on later dates rather than using a random split.
- Cleaning: Non-positive and missing weights are replaced using the median of valid training weights. Missing market-index values use a same-day median where values are available, with a training-period overall median as fallback. Holdout-day market medians use the available holdout features, not their posted rates; this evaluates a batch-prediction setting.
- Features: Pickup and delivery cities and coordinates, distance, equipment, weight, market index, quote signal, month, day of week, and days since January 1, 2025. load_id, posted_rate, and exploratory rate_per_mile are not used as model inputs.
- Comparison: Distance-only linear regression, CatBoost with all date features, CatBoost without month and days-since-start, and CatBoost with training loads filtered to $1–$5 per mile. All were evaluated on the same full chronological holdout using MAE and RMSE.
- Selected model: CatBoost with 14 features and the $1–$5/mile training-only filter. It achieved a holdout MAE of $118.01 and RMSE of $636.95. The filter excludes unusual training prices but does not remove prediction loads. The price-range filter is an empirical modeling choice, not proof that excluded rates are errors.
- Final fit: The selected model is refitted on eligible January–October development loads before making predictions for all 12,000 November–December loads.
The December chart uses the fixed Lexington-to-Fort Wayne shipment in the provided input file. Coordinates are derived from matching locations in the labeled dataset; unavailable market index and quote signal values are held constant at their development-data medians. Only the date changes across the 31 rows.
Validate outputs and generate the December chart
From the project root, run the provided scoring script without modifying it:
python score.py \
  --predictions outputs/validation_predictions.csv \
  --december-predictions outputs/december_predictions.csv \
  --output-dir outputs/scorer_results
